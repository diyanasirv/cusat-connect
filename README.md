# cusat-connect

CUSAT Connect is a centralized digital hub designed specifically for the student community at Cochin University of Science and Technology. The platform breaks down departmental silos by providing a unified space for academic collaboration, peer networking, and essential campus updates.

## 🚀 Key Features

- **Academic Resource Sharing:** Easily upload, categorize, and download semester-wise notes, previous year question papers, and lab manuals.
- **Cross-Department Networking:** Connect with engineering and science students across the campus for interdisciplinary project collaboration.
- **Campus Hub:** A clean interface to stay informed about university circulars, exam registrations, and technical fest announcements.
- **Profile Completion:** Seamless user onboarding with dedicated verification parameters for authentic student accounts.
